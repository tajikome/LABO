■ 使い方（Windows 10/11）
  【方法1：一括で適用する（推奨・一番かんたん）】
    フォルダ内の「マウスカーソルを一括適用.bat」をダブルクリックするだけで、
    全17種類のカーソルがWindowsのマウス設定に即座に一括適用されます！
    ※ 元に戻したいときは「Windows標準に戻す.bat」をダブルクリックしてください。

  【方法2：手動で個別に設定する】
    設定 → Bluetooth とデバイス → マウス → その他のマウス設定
    （または コントロールパネル → マウスのプロパティ）→「ポインター」タブ →
    該当する操作を選び「参照」から対応するファイルを指定 → OK

■ 付属の変換・生成ツール
  - 一括カーソル変換.bat (convert_all_cursors.ps1)
    ・ダブルクリック：hotspot_reference_sheet.png から全17種を見切れなく一括再生成します。
    ・ドラッグ＆ドロップ：任意のPNG画像をこのバッチに重ねると、即座に 64x64 の .cur に変換します。
  - 待機モーション作成.bat (generate_busy_ani.ps1)
    ・03 待機中（03_Busy.ani）の祈りポーズ＋キラキラ星アニメーションを単体生成します。

■ ホットスポット（クリック判定位置）
  同梱の hotspot_reference_sheet.png に、全17種の実際のクリック判定位置を
  緑の十字マークで表示しています。想定と違う場合はお知らせください。

  仕様に明記されていたもの：
    通常選択／範囲選択 … 杖の先端
    テキスト選択       … I字カーソルの中央下端
    移動／リサイズ4種  … アイコンの中央（交点）
    精密選択           … 虫眼鏡の先端
  明記がなく、標準カーソルの慣例に合わせたもの：
    ヘルプ／待機中／作業中 … 図柄の先端付近
    リンク選択             … 鎖アイコンの上側の突起
    場所選択               … 照準アイコンの中心
    人物選択               … フレームアイコンの中心

■ アニメーションについて（待機中・作業中）
  キャラクター本体を固定し、キラキラ・雫など動く部分だけをアニメーション化。
  10フレーム、1フレーム約133ms、ループ再生。

■ 素材について
  新しい参考画像（1536×1024px）から背景・カード枠・文字を除去して使用。
  64px単一サイズのため、前バージョンより全体的にくっきり表示されます。
